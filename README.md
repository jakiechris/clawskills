# Clawskills: A Bilingual Overview

## Project Overview
**Clawskills** is an innovative tool designed to enhance coding productivity, specifically tailored for the OpenClaw/Claude Code/OpenCode project. The repository hosts a range of skills that facilitate various coding tasks while supporting bilingual functionality.

## Why a Case-by-Case MCP Conversion Approach?
Utilizing a case-by-case MCP (Multi-Channel Processing) conversion approach allows for flexibility and adaptability in handling different project requirements. This method ensures that transformations are optimized for specific scenarios, enhancing overall efficiency and effectiveness.

## Chrome DevTools Skill Catalog
The project includes a comprehensive catalog of skills that integrate with Chrome DevTools, offering developers the tools they need to debug and improve their applications seamlessly. The catalog is regularly updated to incorporate the latest features and best practices.

## Getting Started Guide
1. **Clone the Repository:** Use `git clone https://github.com/jakiechris/clawskills.git` to get a local copy.
2. **Install Dependencies:** Run `npm install` to install necessary packages.
3. **Start Learning:** Navigate to the skill catalog and select a skill to begin enhancing your coding experience.

## Project Structure
- `skills/` : Contains various skill implementations.
- `tests/` : Unit tests for each skill.
- `docs/` : Documentation related to usage and contributions.

## Key Concepts
- **Skills:** Modular functionalities that can be integrated into development workflows.
- **MCP Conversion:** The process of adapting skills for optimized performance based on specific cases.

## Warning
Please disable OpenClaw's built-in mcporter skill to avoid conflicts with the Clawskills functionalities. Make sure to review the documentation for further details on how to manage this setting.
